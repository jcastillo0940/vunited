# Web Backend

Backend objetivo para identidad, administración, CMS, noticias, páginas, menús,
jugadores, cuerpo técnico, directiva, patrocinadores, estadio y configuración global.

Base de datos propia: `veraguas_web`.

Durante la migración, el código operativo permanece en la aplicación Laravel de la
raíz. Este backend se activará solamente después de migrar datos, ejecutar pruebas
contractuales y completar el cambio de tráfico documentado.
