# Referencia visual institucional

La referencia es el frontend institucional existente y el análisis visual guardado
en `docs/frontend/phase-2-visual-analysis.md`. Deben conservarse logo, header,
ticker, menú, footer, cards, formularios, botones y responsive.

Tokens observados: azul primario `#1D428A`, celeste `#5BC2E7`, fondo blanco,
superficie `#F4F6F9`, texto `#2B2B2B`; tipografías Oswald para display e Inter para
UI/cuerpo; Material Symbols Outlined para iconos. El layout usa contenedor
`max-w-7xl`, gutters de 16–24 px y colapso a una columna en móvil.

No se modificó el diseño durante la Fase 1. Se guardó una captura de referencia del
home local en `docs/architecture/assets/phase1-home.png`; la captura muestra el
header/ticker, navegación, CTA y shell institucional. La validación responsive
completa queda pendiente de un entorno HTTP de QA con viewport controlado.
